# E-commerce-Sales-Analysis-SQL
E-commerce Sales Analysis using MySQL to analyze revenue, product performance, customer spending, and sales trends.

## Project Overview

This project analyzes e-commerce sales data using MySQL to identify sales trends, product performance, customer spending, and order status.

 Tools Used

* MySQL
* MySQL Workbench
* SQL

 Database Tables

* Customers
* Products
* Orders
* Order_Items

 SQL Concepts Used

* Joins
* Aggregate Functions
* GROUP BY and HAVING
* Subqueries
* Common Table Expressions (CTEs)
* Window Functions
* RANK()
* ORDER BY and LIMIT

 Business Analysis

* Total revenue from delivered orders
* Total orders by status
* Average order value
* Monthly revenue trends
* Highest revenue-generating products
* Product category performance
* Top 5 customers by spending
* Repeat customer analysis
* Customer spending rankings
* Customer spending compared with average spending

 Key Objectives

* Analyze sales performance.
* Identify high-performing products.
* Understand customer purchasing behavior.
* Track order statuses.
* Generate insights to support business decisions.

 Dataset

This project uses sample e-commerce data created for SQL practice and learning purposes.
